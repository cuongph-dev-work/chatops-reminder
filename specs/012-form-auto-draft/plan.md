# Implementation Plan: Form Auto-Draft

**Branch**: `012-form-auto-draft` | **Date**: 2026-03-28 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/012-form-auto-draft/spec.md`

## Summary

Implement an auto-drafting feature for the "New Reminder" form. The form state will be continuously saved to `chrome.storage.local` with a timestamp. If the extension popup closes unexpectedly, reopening it within 15 minutes will restore the draft. Drafts older than 15 minutes or drafts from successfully saved reminders will be purged.

## Technical Context

**Language/Version**: TypeScript 5+, React 18  
**Primary Dependencies**: `@plasmohq/storage/hook`, `react`  
**Storage**: `chrome.storage.local` (via Plasmo Storage)  
**Testing**: Manual testing via Chrome Extensions UI  
**Target Platform**: Chrome Extension (MV3)  
**Project Type**: Browser Extension (Popup UI)  
**Performance Goals**: Negligible typing latency (needs debouncing for storage writes if necessary, or `useStorage` default behavior)  
**Constraints**: Popup closes immediately on blur; state must be saved cleanly.  
**Scale/Scope**: Single draft object at a time.

- **UI & Aesthetics**: The save implementation is entirely invisible / background logic. No UI changes require new stylings, maintaining the existing slate/blue theme.
