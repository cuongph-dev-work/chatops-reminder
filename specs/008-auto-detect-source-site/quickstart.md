# Quickstart: Auto-Detect Source Site

```bash
pnpm dev
```

1. Navigate to any website (e.g., `https://github.com`)
2. Open the extension popup → click "New Reminder"
3. Verify the Link field is auto-filled with the current page URL
4. Save the reminder → check Settings → verify "Site Mappings" shows `github.com`
5. Wait for the notification → verify "From: GitHub" subtitle appears
